How it works & privacy

How the numbers work

Yearly cost is the entered price multiplied by 12 for monthly billing, by 4 for quarterly billing, and by 1 for annual billing. Monthly averages are yearly totals divided by 12. Totals are calculated before rounding for display, so rounded row amounts can differ slightly from rounded totals.

Potential savings assume all marked recurring charges stop for a full year. This is not an immediate refund estimate. Prepaid terms, cancellation fees, notice periods, taxes not included in your price, changing prices, and partial-year billing are not modelled. Check each provider's terms. No subscriptions are cancelled, no bank or provider accounts are connected, and no reminders are sent.

Each list uses one currency. The selector is locked while the list contains entries so existing amounts cannot be relabelled as another currency. Delete the entries or start an empty list to choose a different currency. This app supports up to 500 subscriptions, each priced from zero to 1,000,000 per billing period.

Privacy, saving, and deleting data

Your own list is automatically saved in this browser's local storage for this site when storage and safe cross-tab coordination are available. It is not uploaded or synced between devices. Anyone using this browser profile may be able to see it. Private browsing, browser cleanup, and storage restrictions can prevent saving or remove entries.

We do not add analytics or send subscription entries to a server. Hosting providers still receive ordinary page requests and may log connection information. Example mode does not save changes. “Delete my data” replaces this app's saved record with an empty list and default settings, leaving only an anonymous random reset marker to prevent older queued saves from restoring deleted entries. No subscription names, prices, or previous currency remain in that reset record. Other apps' data are not changed. Deletion does not affect any real subscriptions or provider accounts.

Saving and deletion use an exclusive Web Lock to prevent overlapping tabs from overwriting each other. If this browser cannot coordinate safely, your saved list is read-only, and no deletion is confirmed. Try a supported modern browser on HTTPS or localhost, or clear this site's data through browser settings. Fictional example mode remains available.
